Installing Animated Java

What you’ll need

  • Blockbench 5.1.4 or newer.
  • Minecraft: Java Edition 1.20.4 or newer.

From the Plugin Manager

  1. Open Blockbench and go to File Plugins… to open the Plugin Manager.

  2. Search for “Animated Java”.

  3. Click Install.

From a URL

To install straight from the latest GitHub release:

  1. Open the Plugin Manager (File Plugins…).

  2. Click Load Plugin from URL.

  3. Paste this URL:

    https://github.com/Animated-Java/animated-java/releases/latest/download/animated_java.js

From a File

If you’ve downloaded animated_java.js yourself:

  1. Open the Plugin Manager (File Plugins…).
  2. Click Load Plugin from File.
  3. Select the downloaded animated_java.js file.

Incompatible plugins

Some Blockbench plugins are known to break Animated Java. If you have one installed, Animated Java shows a popup listing them, with buttons to disable them.
